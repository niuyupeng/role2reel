# Post-composite text

Screen text is a separate production layer. Mark text that must be exact, legible, or stable as `POST_COMPOSITE_TEXT` rather than assuming a video model will render it correctly.

Typical candidates include percentages, countdowns, coordinates, code, system messages, subtitles, title cards, credits, chapter labels, and transition captions. Generate a clean plate with the screen, sign, or surface readable enough for the later overlay; reserve the required hold and actor reaction in the editorial clock. Then add the exact text in compositing or an explicitly approved text-capable stage.

If text is intentionally generated in-world, record its source, language, spelling approval, target surface, interval, and a fallback repair. Do not let an unrequested model hallucination become story fact. Keep the fixed five-field paste format unchanged; put the label and implementation note in the workbook/audit metadata or inside the relevant `画面与动线` description.

Text compositing does not excuse a missing cause or reaction. A percentage that changes the stakes still needs a readable state handoff, and a subtitle still needs natural speech timing.
